**Network admin in the native engine.** What you used to open the official Radmin window for is now in the app.

### Highlights
* **Admin tools**: right click a network you administer to delete it for everyone (you type its name to confirm). Right click a member to make them admin, remove admin or remove them from the network
* ★ marks your admin networks and the admins in each one; "(waiting for approval)" when a join needs an admin
* **Block an IP**: right click a member > Block this IP (both ways, only incoming or only outgoing). Silent and local, the peer is not told. Network > Blocked addresses… unblocks
* **Network > Use relays only** for networks where direct UDP/TCP fails, and **Retry failed peers**
* Ping now on any member; Join and Create check the 6 to 256 character password rule first

Install or update:

    curl -fsSL https://raw.githubusercontent.com/gabrielmf1998/Radmin-Linux/main/bootstrap.sh | bash

From the GitLab mirror: `curl -fsSL https://gitlab.com/gabriel17166/radmin-linux/-/raw/main/bootstrap.sh | RADMIN_MIRROR=gitlab bash`

Or Help > Check for app updates in the app. These features need the native engine (default since 0.6.0); the VM engine is unchanged.

Full list in [CHANGELOG.md](https://github.com/gabrielmf1998/Radmin-Linux/blob/v0.7.0/CHANGELOG.md).
