**Fix: changing your name now reaches the other members.**

Windows users on official Radmin kept seeing your old name after you changed it. OpenRad only saved the name on your PC, and the Radmin server ignores the name sent at login. Official Radmin renames with its own server command, and the server then sends the new name to everyone in your networks. OpenRad now does the same: a rename while connected is sent at once, a rename while offline is sent when you connect, and names changed by others update live.

Tested against the official Radmin server: the other side saw the new name, live updates arrived in about 4 seconds without reconnecting, and an offline rename was delivered on connect.

This release ships **OpenRad 2.4.5-rl.1**, upstream [OpenRad](https://github.com/gringoestrangeiro/openrad) 2.4.5 (MIT) plus the fix. The patch and build steps are in [`packaging/openrad`](https://github.com/gabrielmf1998/Radmin-Linux/tree/main/packaging/openrad). Built on Debian 11, runs on Ubuntu 20.04, Debian 11 and newer.

Install or update:

    curl -fsSL https://raw.githubusercontent.com/gabrielmf1998/Radmin-Linux/main/bootstrap.sh | bash

From the GitLab mirror: `curl -fsSL https://gitlab.com/gabriel17166/radmin-linux/-/raw/main/bootstrap.sh | RADMIN_MIRROR=gitlab bash`

### Assets
* `openrad-v2.4.5-rl.1-linux-x86_64.tar.gz`, the OpenRad build the installer downloads (sha256 pinned in `OPENRAD_VERSION`)
* `openrad-v2.4.5-rl.1.patch`, the change against upstream 2.4.5
* Arch package

The VM engine still takes its image from [v0.3.0](https://github.com/gabrielmf1998/Radmin-Linux/releases/tag/v0.3.0) (named in `IMAGE_VERSION`).
