**Fix: the app did not open with the native engine.**

Opening Radmin VPN from the menu showed "Could not prepare the link to the VM ... could not create tapradmin". The launcher still checked the VM link, which the native engine (OpenRad, default since 0.6.0) does not use. Now it only checks Python and OpenRad in native mode. The VM engine is unchanged.

Install or update:

    curl -fsSL https://raw.githubusercontent.com/gabrielmf1998/Radmin-Linux/main/bootstrap.sh | bash

From the GitLab mirror: `curl -fsSL https://gitlab.com/gabriel17166/radmin-linux/-/raw/main/bootstrap.sh | RADMIN_MIRROR=gitlab bash`

### Assets
Arch package only. The VM engine still takes its image from [v0.3.0](https://github.com/gabrielmf1998/Radmin-Linux/releases/tag/v0.3.0) (named in `IMAGE_VERSION`).
