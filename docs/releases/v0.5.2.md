**"Shutting down" instead of "Starting" while the VM turns off.** A VM that was going away looked the same as one coming up (the process was still there and the agent had stopped answering), so the app said "Starting… VM is booting". The VM image is the same as 0.3.0, so upgrading downloads only the app.

Install or upgrade (keeps your VM and your Radmin identity):

    curl -fsSL https://raw.githubusercontent.com/gabrielmf1998/Radmin-Linux-KDE/main/bootstrap.sh | bash

From the GitLab mirror: `curl -fsSL https://gitlab.com/gabriel17166/radmin-linux/-/raw/main/bootstrap.sh | RADMIN_MIRROR=gitlab bash`

From 0.4.0 or later: **Help > Check for app updates**.

### Highlights
* "Shutting down… / VM is turning off, please wait", badge "Stopping", tray "shutting down"
* Same for the power button, the tray menu and `bench-stop.sh`
* The power button cannot start a second shutdown, Connect is disabled meanwhile; the watchdog leaves a shutting down VM alone; no "stopped" alert when you turned it off
* Turning off waits up to 2 minutes for Windows, then stops the VM (like `bench-stop.sh`)

Full list in [CHANGELOG.md](https://github.com/gabrielmf1998/Radmin-Linux-KDE/blob/v0.5.2/CHANGELOG.md).
