**The list only shows what Radmin shows, and the VM no longer waits on the Windows activation dialog.** The app keeps the list empty until the VM agent has a complete reading of the Radmin window, so old peers, guessed groups and networks you already left no longer flash by while Windows starts. The VM image is the same as 0.3.0, so upgrading downloads only the app.

Install or upgrade (keeps your VM and your Radmin identity):

    curl -fsSL https://raw.githubusercontent.com/gabrielmf1998/Radmin-Linux-KDE/main/bootstrap.sh | bash

From the GitLab mirror: `curl -fsSL https://gitlab.com/gabriel17166/radmin-linux/-/raw/main/bootstrap.sh | RADMIN_MIRROR=gitlab bash`

From 0.4.0 or later: **Help > Check for app updates**. The agent in the VM upgrades itself to version 6 on the next refresh.

### Highlights
* The list stays empty ("reading the Radmin window…") until the reading is complete; no old peers, old groups or left networks meanwhile
* The reader publishes only after the Radmin window has settled
* "Leave network" opens the Radmin window instead of trusting the registry, which keeps networks you left
* The "Activate Windows now" dialog is closed at logon (same as "Ask me later"): the VM desktop is ready 8 s after logon instead of about 2 minutes
* The old ARP list and "Sync members" only come back when the VM agent could not be updated

Full list in [CHANGELOG.md](https://github.com/gabrielmf1998/Radmin-Linux-KDE/blob/v0.5.1/CHANGELOG.md).
