**Quit closes everything.** Quitting from the tray (or File > Quit) now turns the VM off, closes the VNC windows showing it and then exits, so nothing keeps running in the background. The VM image is the same as 0.3.0, so upgrading downloads only the app.

Install or upgrade (keeps your VM and your Radmin identity):

    curl -fsSL https://raw.githubusercontent.com/gabrielmf1998/Radmin-Linux-KDE/main/bootstrap.sh | bash

From the GitLab mirror: `curl -fsSL https://gitlab.com/gabriel17166/radmin-linux/-/raw/main/bootstrap.sh | RADMIN_MIRROR=gitlab bash`

From 0.4.0 or later: **Help > Check for app updates**.

### Highlights
* Quit turns the VM off (Windows gets up to 2 minutes, then the VM is stopped), closes the VM viewers and cancels a VM start in progress, then exits
* While it does that the tray says "turning the VM off, then quitting"; with the VM already off the app exits at once
* Quit with the window open really quits now
* Logout with the app open shuts the VM down too (stopped after 2 minutes if Windows hangs)
* Restarting after an app update keeps the VM on

Full list in [CHANGELOG.md](https://github.com/gabrielmf1998/Radmin-Linux-KDE/blob/v0.5.3/CHANGELOG.md).
