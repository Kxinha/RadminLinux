**The peer list now matches the Radmin window.** The VM agent reads the real Radmin window (network names, members, IPs) and Radmin's own log (who is connected, direct or relay), so the app no longer guesses from ARP or a memory dump. The VM image is the same as 0.3.0, so upgrading downloads only the app.

Install or upgrade (keeps your VM and your Radmin identity):

    curl -fsSL https://raw.githubusercontent.com/gabrielmf1998/Radmin-Linux-KDE/main/bootstrap.sh | bash

From the GitLab mirror: `curl -fsSL https://gitlab.com/gabriel17166/radmin-linux/-/raw/main/bootstrap.sh | RADMIN_MIRROR=gitlab bash`

From 0.4.0: **Help > Check for app updates**. The agent in the VM upgrades itself to version 5 on the next refresh.

### Highlights
* One section per Radmin network with its real name and "online/total"
* Exactly the members Radmin shows; stale peers from old networks are gone
* Online straight from Radmin, so peers that block ping are no longer shown offline; "relay" when Radmin uses one
* Refresh every 5 s with the window open (`/state` ~15 ms), 60 s in the tray
* "＋ Network" offers Join or Create
* Agent reader: ~50 MB and under 1% of the VM CPU; the VM stays at ~3% of one host core

Full list in [CHANGELOG.md](https://github.com/gabrielmf1998/Radmin-Linux-KDE/blob/v0.5.0/CHANGELOG.md).
