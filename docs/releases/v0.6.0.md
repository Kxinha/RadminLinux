**Radmin VPN on Linux without a VM.** The window and tray now drive [OpenRad](https://github.com/gabrielmf1998/openrad), an open source (MIT) Radmin VPN client by [gringoestrangeiro](https://github.com/gringoestrangeiro/openrad), as the default engine. No Windows, no qemu, no 3 GB image: the install downloads a few MB and creates a `radminvpn0` interface with your 26.x address.

Install (native engine):

    curl -fsSL https://raw.githubusercontent.com/gabrielmf1998/Radmin-Linux/main/bootstrap.sh | bash

From the GitLab mirror: `curl -fsSL https://gitlab.com/gabriel17166/radmin-linux/-/raw/main/bootstrap.sh | RADMIN_MIRROR=gitlab bash`

**Already using the VM?** Updating keeps you on the VM. To switch, run the curl command with `RADMIN_ENGINE=openrad` before `bash`; `RADMIN_ENGINE=vm` switches back. The VM image is never touched.

### Highlights
* Power on and off, Join a network and Create network (name and password right in the app), Leave, Rename node, Reset identity, Diagnostics, Retry the network interface
* Peers with UDP / TCP / TcpRelay and ping time, like before
* One pkexec prompt at install; a per user polkit rule then lets only `openrad tap-helper` create the interface without a password
* OpenRad is downloaded from our copy of its v2.4.5 release and checked against a pinned sha256

### Good to know
* The native engine is a **new Radmin identity**: join your networks again
* Only one engine at a time (both use 26.0.0.0/8)
* OpenRad is a third party reimplementation, not made or supported by Famatech; the Radmin VPN EULA forbids reverse engineering the official client
