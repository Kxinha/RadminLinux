**In-app updates, a tray that shows the state, ping times per peer and a lighter refresh.** The VM image is the same as 0.3.0, so upgrading downloads only the app.

Install or upgrade (keeps your VM and your Radmin identity):

    curl -fsSL https://raw.githubusercontent.com/gabrielmf1998/Radmin-Linux-KDE/main/bootstrap.sh | bash

From the GitLab mirror: `curl -fsSL https://gitlab.com/gabriel17166/radmin-linux/-/raw/main/bootstrap.sh | RADMIN_MIRROR=gitlab bash`

From 0.4.0 on, **Help > Check for app updates** does this from the app.

### Highlights
* In-app updates with a quiet daily check (can be turned off)
* Ping time next to each online peer, right click > Copy IP
* Tray icon with status dot, optional notification when Radmin stops
* Settings: start with the session in the tray, turn the VM on with the app
* One instance only; status messages stay readable
* Lighter: rows reused, slower polling while hidden, `/state` in 13 ms, self repair every 10 min
* Fixes: accented peer names, ghost process without a tray, upgrades no longer disturb a running VM

Full list in [CHANGELOG.md](https://github.com/gabrielmf1998/Radmin-Linux-KDE/blob/v0.4.0/CHANGELOG.md).

### Assets
No image in this release: `bootstrap.sh` takes the VM image from [v0.3.0](https://github.com/gabrielmf1998/Radmin-Linux-KDE/releases/tag/v0.3.0) (named in `IMAGE_VERSION`).
