**Every install now gets its own Radmin identity**, the app is instant, the VM is light, and the curl installer resumes and verifies.

Install or upgrade (keeps your VM):

    curl -fsSL https://raw.githubusercontent.com/gabrielmf1998/Radmin-Linux-KDE/main/bootstrap.sh | bash

From the GitLab mirror: `curl -fsSL https://gitlab.com/gabriel17166/radmin-linux/-/raw/main/bootstrap.sh | RADMIN_MIRROR=gitlab bash`

### Important if you used 0.1.0
The 0.1.0 image shipped with one shared Radmin identity, so all its users were the same node and saw the same networks. After upgrading, the first start gives you a **new node** (new 26.x address, no networks): join your networks again. Network owners: remove members that joined with a 0.1.0 install and change the network password.

### Highlights
* Own identity per install, plus **System > Reset Radmin identity**
* Refresh in ~0.1 s (agent API in the VM instead of a WMI login per refresh)
* Idle VM ~2% of one core; Windows trimmed and firewalled
* **Open the Radmin window** brings Radmin to the front, lossless VNC picture
* Installer: progress bar, resume, SHA256 check, no `/tmp`, one password prompt, `uninstall.sh`

Full list in [CHANGELOG.md](https://github.com/gabrielmf1998/Radmin-Linux-KDE/blob/v0.3.0/CHANGELOG.md).

### Assets
`radmin-linux-base.qcow2.zst.part-*` is the VM image split in parts under 2 GB; `bootstrap.sh` downloads and joins them. `SHA256SUMS` covers every part.
