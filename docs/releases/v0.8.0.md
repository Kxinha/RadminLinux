**Looks and works like Radmin VPN.** Same window, menus, dialogs and tray as Radmin, with the native OpenRad engine underneath.

![screenshot](https://raw.githubusercontent.com/gabrielmf1998/Radmin-Linux/v0.8.0/assets/screenshot.png)

### Highlights
* Radmin's palette, title bar and round **power button**, your name, IP and Online badge on top
* Networks as blue pills, members with green signal bars; hover for IP, status, channel and ping
* Menus **System / Network / Help** with Radmin's names and shortcuts (Ins, +, F1, F5); Change Name edits in place
* **Join Network** with Private Network and Gaming Network tabs (search public networks, member counts)
* **Create Network** with password confirmation, **Properties** for networks and members (admins change roles there)
* **Settings** with General, Advanced and Notifications; the Linux extras (relays only, retry peers, blocked addresses, diagnostics) are in Advanced
* Right click menus like Radmin: Leave, Delete, Copy Network Name, Copy IP Address, Ping, Remove, Grant Admin Rights, Properties
* Tray: Open, Go Online or Go Offline, Exit

Not included because OpenRad does not provide them: chat, Disable Network, Radmin Server items, network parameters and password change, firewall exceptions, IPv6.

Install or update:

    curl -fsSL https://raw.githubusercontent.com/gabrielmf1998/Radmin-Linux/main/bootstrap.sh | bash

From the GitLab mirror: `curl -fsSL https://gitlab.com/gabriel17166/radmin-linux/-/raw/main/bootstrap.sh | RADMIN_MIRROR=gitlab bash`

Or Help > Check for Updates in the app. The VM engine gets the same look; its behavior is unchanged.

Full list in [CHANGELOG.md](https://github.com/gabrielmf1998/Radmin-Linux/blob/v0.8.0/CHANGELOG.md).
