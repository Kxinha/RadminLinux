**Verified with the official Radmin VPN on Windows, and Linux can now host for Windows friends.**

### Tested against official Radmin VPN (Windows)
| test | result |
|---|---|
| Windows creates a network, Linux joins | works |
| Linux creates a network, Windows joins (Radmin's Join Network) | works |
| ping both ways | 4/4 each way |
| TCP and UDP, Linux to Windows | works |
| TCP and UDP, Windows to Linux | works with Firewall Exceptions (new) |
| grant admin, remove member, delete network across both apps | works |

### New: System > Firewall Exceptions (like Radmin)
The test showed Linux firewalls (firewalld, ufw) answer ping on the VPN interface but refuse connections, so Windows friends could not join a server hosted on Linux.
* **Add Application** lists your programs waiting for connections and opens only their ports, only for VPN peers
* **Allow All Apps** opens the whole VPN interface
* Asks for the admin password once, survives reboot, removed by the uninstaller

### Also
* With no network, Create Network and Join Network buttons in the middle of the window, as in Radmin
